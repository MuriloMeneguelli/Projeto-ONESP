# Projeto-ONESP
Criação de uma página de notícias fictícia chamada ONESP


Tive a ideia de criar este projeto ao estudar grouping tag´s, já sabia o que eram pórem decidi testar meus conhecimentos e capacidades.

Tecnologias usadas no projeto: 

HTML5: Estruturação do projeto
CSS3: Estilização do projeto.

O que o projeto contém? 

Estrutura HTML semântica e organizada.
Estilização organizada e bem pensada.
Páginação completa das notícias.
